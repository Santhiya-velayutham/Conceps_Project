## Project Overview:

This is a React admin/dashboard project with Sign Up, Sign In, OTP verification, and product management features. It has a modern, responsive, and interactive UI with dark mode support.

Key Features:

Authentication: Sign Up, Sign In, OTP verification

Dashboard: Sidebar navigation, info cards, charts, and tables

Products: Product listing, details page, and Buy button

Design: Split screen forms, gradient buttons, hover effects, responsive layout, dark mode

Tech Used: React, React Router, CSS, Local Storage

Purpose: Manage users, view analytics, and handle products easily in a modern dashboard interface.


## install the this package is must:
npm install
npm react-router-dom
npm install chart.js react-chartjs-2
npm install react-icons
npm install @fortawesome/react-fontawesome @fortawesome/free-solid-svg-icons
